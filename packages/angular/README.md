# StateQL Angular integration

Reserved module for DI, signal projections, reactive argument changes, and lifecycle cleanup. Angular is the first framework integration.

The adapter observes the shared core runtime. It must not duplicate fetching, retries, caching, or invalidation. Add Angular peer dependencies and Angular Package Format tooling when implementing this package; a plain TypeScript build is not a substitute for packaging Angular declarations correctly.

No Angular implementation or npm release exists in this foundation milestone.
